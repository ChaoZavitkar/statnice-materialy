Okruh 11 – Rekurence, speciální funkce a asymptotická analýza

KI/SZZTP – Teoretické základy informatiky

Rekurence

Definice

Rekurentní vztah (recurrence relation): Rovnice, která definuje posloupnost tím, že vyjadřuje každý člen jako funkci předchozích členů.

Příklady:

  • Fibonacciho posloupnost: $F(n) = F(n-1) + F(n-2)$ s $F(0)=0, F(1)=1$
  • Faktoriál: $n! = n \cdot (n-1)!$ s $0!=1$
  • Věž z Hanoje: $T(n) = 2 \cdot T(n-1) + 1$ s $T(1)=1$

Klíčové prvky rekurence:

  • Báze (initial condition): Hodnoty pro malé n (např. $F(0)=0$)
  • Rekurzivní krok: Jak se vypočítá $F(n)$ z menších hodnot

Metoda 1: Iterační metoda

Princip: Postupně nahrazuj rekurzivní volání, dokud nedosáhneš báze. Pak sečti všechny členy.

Příklad: $T(n) = T(n-1) + n$ s $T(1) = 1$

$T(n) = T(n-1) + n$
$= T(n-2) + (n-1) + n$
$= T(n-3) + (n-2) + (n-1) + n$
$= \ldots = T(1) + 2 + 3 + \ldots + n$
$= 1 + 2 + 3 + \ldots + n = \frac{n(n+1)}{2}$

Výsledek: $T(n) = O(n^2)$

Metoda 2: Substituční metoda

Princip: Uhádni řešení (tvar funkce) a dokaž jeho správnost indukcí.

Příklad: $T(n) = 2T(n-1) + 1$ s $T(1) = 1$

Domněnka: $T(n) = 2^n - 1$

Indukční důkaz:
• Báze: $T(1) = 2^1 - 1 = 1$ ✓
• Krok: Předpokládáme $T(n) = 2^n - 1$
$T(n+1) = 2T(n) + 1 = 2(2^n - 1) + 1 = 2^{n+1} - 2 + 1 = 2^{n+1} - 1$ ✓

Metoda 3: Master theorem

Master theorem: Řeší rekurence tvaru $T(n) = a \cdot T(n/b) + f(n)$

Existují tři případy (podrobnější formulace):

Případ Podmínka Řešení
1 $f(n) = O(n^{\log_b a - \epsilon})$ pro nějaké $\epsilon > 0$ $T(n) = \Theta(n^{\log_b a})$
2 $f(n) = \Theta(n^{\log_b a} \log^k n)$ $T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$
3 $f(n) = \Omega(n^{\log_b a + \epsilon})$ a $a \cdot f(n/b) \leq c \cdot f(n)$ $T(n) = \Theta(f(n))$
Příklad: $T(n) = 4T(n/2) + n$

• $a = 4, b = 2$, tak $\log_b a = \log_2 4 = 2$
• $f(n) = n = O(n^{2-\epsilon})$ pro $\epsilon = 1$ → Případ 1
• $T(n) = \Theta(n^2)$

Řešení převodem na algebraické rovnice

Generující funkce: Sečti všechny členy formální řady a vyřeš algebraicky.

Příklad: $F(n) = F(n-1) + F(n-2)$ (Fibonacciho posloupnost)

Definuj $G(x) = \sum_{n=0}^{\infty} F(n) x^n$

Pak lze ukázat, že $G(x) = \frac{x}{1 - x - x^2}$

Pomocí parciálních zlomků lze získat explicitní formuli (Binetův vzorec)

Příklady

Příklady, které SPLŇUJÍ definici rekurentního vztahu:

  • $F(n) = F(n-1) + F(n-2)$ — Fibonacciho posloupnost (každý člen je součet dvou předchozích)
  • $T(n) = 2 \cdot T(n/2) + n$ — Merge sort (rozděluj a panuj)
  • $n! = n \cdot (n-1)!$ — Faktoriál
  • $H(n) = 2 \cdot H(n-1) + 1$ — Věž z Hanoje

Příklady, které NESPLŇUJÍ definici rekurentního vztahu:

  • $F(n) = 1$ pro všechna $n$ — nemá žádný rekurzivní odkaz
  • $F(n) = \sin(n)$ — není definován rekurzivně
  • Relace bez базе: $F(n) = F(n-1) + 1$ bez $F(0)$ — není jasné, jak začít
  • Nekonečný spád: $F(n) = F(n+1)$ — nikdy se nedosáhne báze

Speciální funkce

Dolní a horní celá část

Dolní celá část (floor): $\lfloor x \rfloor$ — největší celé číslo $\leq x$

Příklady:
• $\lfloor 3.7 \rfloor = 3$
• $\lfloor 5 \rfloor = 5$
• $\lfloor -2.3 \rfloor = -3$ (ne -2!)

Horní celá část (ceiling): $\lceil x \rceil$ — nejmenší celé číslo $\geq x$

Příklady:
• $\lceil 3.2 \rceil = 4$
• $\lceil 5 \rceil = 5$
• $\lceil -2.3 \rceil = -2$

Vztah mezi nimi:

  • $\lfloor x \rfloor + 1 = \lceil x \rceil$ když $x \notin \mathbb{Z}$
  • $\lfloor x \rfloor = \lceil x \rceil$ když $x \in \mathbb{Z}$
  • $\lfloor -x \rfloor = -\lceil x \rceil$

Logaritmy

Logaritmus: Inverzní funkce k exponenciále. $\log_b x = y$ znamená $b^y = x$

Základní vlastnosti:

  • $\log_b (x \cdot y) = \log_b x + \log_b y$
  • $\log_b (x / y) = \log_b x - \log_b y$
  • $\log_b (x^k) = k \cdot \log_b x$
  • $\log_b b = 1$
  • $\log_b 1 = 0$
  • Změna základu: $\log_b x = \frac{\log_a x}{\log_a b}$

Speciální logaritmy:

  • $\log_2 x$ — binární logaritmus (informatika)
  • $\log_{10} x$ — dekadický logaritmus
  • $\ln x$ — přirozený logaritmus (základ $e$)
Důležité: V analýze algoritmů se obvykle píše $\log n$ bez základu — znamená to $\log_2 n$ (binární logaritmus), protože závisí na počtu bitů a dělení na poloviny.

Asymptotická notace

Velké O notace (O-notace)

Definice: $f(n) = O(g(n))$ znamená, že existují konstanty $c > 0$ a $n_0$ takové, že: $$f(n) \leq c \cdot g(n) \text{ pro všechna } n \geq n_0$$

Intuice: $f(n)$ roste nejvíce tak rychle jako $g(n)$ (horní mez).

Příklady:
• $3n^2 + 5n + 7 = O(n^2)$ (kvadratická)
• $100n = O(n)$ (lineární)
• $\log n = O(n)$ (logaritmus je menší než lineární)
• $n^2 \neq O(n)$ (kvadratická není menší než lineární)

Příklady

Příklady, které SPLŇUJÍ $O(n^2)$:

  • $3n^2 + 5n + 7$ ✓ (dominuje kvadratický člen)
  • $n^2$ ✓ (přesně kvadratická)
  • $5n + 100$ — NESPLŇUJE! (lineární je menší, ale není kvadratická)
  • $n^3$ — NESPLŇUJE! (kubická je větší než kvadratická)

Příklady, které SPLŇUJÍ $\Theta(n \log n)$:

  • $n \log n + 5n$ ✓ (dominuje člen $n \log n$)
  • $100 n \log n$ ✓ (konstanta před není důležitá)
  • $n \log n + n^2$ — NESPLŇUJE! (dominuje $n^2$, ne $n \log n$)
  • $n^2$ — NESPLŇUJE! (kvadratická je větší než $n \log n$)

Praktická pamatování:

  • $O(g(n))$ — horní mez (v nejhorším případě)
  • $\Omega(g(n))$ — dolní mez (v nejlepším případě)
  • $\Theta(g(n))$ — přesná složitost (vázaná z obou stran)

Theta notace (Θ-notace)

Definice: $f(n) = \Theta(g(n))$ znamená, že existují konstanty $c_1 > 0, c_2 > 0$ a $n_0$ takové, že: $$c_1 \cdot g(n) \leq f(n) \leq c_2 \cdot g(n) \text{ pro všechna } n \geq n_0$$

Intuice: $f(n)$ roste právě tak rychle jako $g(n)$ (těsný odhad).

Příklady:
• $3n^2 + 5n + 7 = \Theta(n^2)$
• $n \log n + 2n = \Theta(n \log n)$
• $2^n + n^{100} = \Theta(2^n)$ (exponenciála dominuje)

Omega notace (Ω-notace)

Definice: $f(n) = \Omega(g(n))$ znamená, že existují konstanty $c > 0$ a $n_0$ takové, že: $$f(n) \geq c \cdot g(n) \text{ pro všechna } n \geq n_0$$

Intuice: $f(n)$ roste nejméně tak rychle jako $g(n)$ (dolní mez).

Příklady:
• $3n^2 + 5n + 7 = \Omega(n^2)$
• $3n^2 + 5n + 7 = \Omega(n)$ (také, protože dominuje $n^2$)
• $n \log n = \Omega(n)$
• $n = \Omega(\log n)$ (lineární je větší než logaritmus)

Vztahy mezi notacemi

Klíčová věta: $f(n) = \Theta(g(n))$ právě když $f(n) = O(g(n))$ AND $f(n) = \Omega(g(n))$

$\Theta(g(n))$ je "správná" třída funkce — není příliš volná (jako O) ani příliš těsná (jako Ω).

Manipulace s asymptotickou notací

Tranzitivita:

  • $f = O(g)$ a $g = O(h)$ $\Rightarrow$ $f = O(h)$
  • $f = \Theta(g)$ a $g = \Theta(h)$ $\Rightarrow$ $f = \Theta(h)$

Sčítání:

  • $O(f(n)) + O(g(n)) = O(\max(f(n), g(n)))$
  • Např. $O(n^2) + O(n) = O(n^2)$

Násobení:

  • $O(f(n)) \cdot O(g(n)) = O(f(n) \cdot g(n))$
  • Např. $O(n) \cdot O(n) = O(n^2)$

Logaritmická hierarchie:

$O(1) \subset O(\log n) \subset O(n) \subset O(n \log n) \subset O(n^2) \subset O(n^3) \subset O(2^n) \subset O(n!)$

Algoritmy

Definice

Algoritmus: Přesný postup (soupis kroků) k vyřešení problému v konečném čase.

Vlastnosti algoritmu:

  • Konečnost (finiteness): Algoritmus musí skončit pro jakýkoliv vstup
  • Determiniovanost: Každý krok je jasně definován, bez dvojznačnosti
  • Efektivnost: Každý krok je elementární (lze jej prakticky vykonat)
  • Vstup/Výstup: Algoritmus přijímá vstup a produkuje výstup

Příklady

Příklady, které SPLŇUJÍ definici algoritmu:

  • Binární vyhledávání: Daný tříděný seznam, najdi prvek nebo řekni, že tam není ✓
  • Třídění (Quicksort, Mergesort): Daný seznam, seřaď jej ✓
  • GCD (Euklidův algoritmus): Daná dvě čísla, najdi jejich největší společný dělitel ✓
  • Ověření primality: Dáno číslo, rozhodněte, zda je prvočíslo ✓

Příklady, které NESPLŇUJÍ definici algoritmu:

  • Nekonečný cyklus: while True: pass — NESPLŇUJE! (nemá konečnost)
  • Neurčitý postup: "Najdi největší číslo v seznamu" bez specifikace, jak to dělat — NESPLŇUJE! (není determinován)
  • Heuristika bez záruky: "Hádej faktory náhodně" — NESPLŇUJE! (nefunguje na všechny vstupy)
  • NP-tvrdý problém bez řešení: "Najdi optimální řešení TSP" bez konkrétního postupu — NESPLŇUJE! (není znám polynomiální postup)

Jak měřit efektivitu algoritmů:

  • Časová složitost: Kolik elementárních operací provede? (funkcí délky vstupu $n$)
  • Prostorová složitost: Kolik paměti potřebuje?

Praktická doporučení pro analýzu algoritmů

Jak si rychle zjistit složitost algoritmu:

  • Jednoduchá smyčka: $O(n)$ 
    for i in range(n):
    # Něco trvá O(1)
  • Vnořené smyčky: $O(n^2)$ 
    for i in range(n):
    for j in range(n):
        # Něco trvá O(1)
  • Rozdělování na poloviny: $O(\log n)$ 
    while n > 1:
    n = n // 2  # dělíme dvěma
  • Kombinace — smyčka s dělením: $O(n \log n)$ 
    for i in range(n):           # O(n)
    search_sorted(arr, i)    # O(log n)

Euklidův algoritmus

Problém: Najít největší společný dělitel (GCD) dvou čísel $a$ a $b$.

Princip: Opakovaně nahrazuj větší číslo zbytkem dělení.

def gcd(a, b):
    while b != 0:
        temp = b
        b = a % b
        a = temp
    return a

# Příklad: gcd(48, 18)
# 48 % 18 = 12
# 18 % 12 = 6
# 12 % 6 = 0 → gcd = 6
Důkaz správnosti: $\gcd(a, b) = \gcd(b, a \bmod b)$ protože:
  • Každý společný dělitel $(a, b)$ je také dělitelem $(b, a \bmod b)$
  • Obráceně, každý společný dělitel $(b, a \bmod b)$ je také dělitelem $(a, b)$

Časová složitost: $O(\log \min(a, b))$ — velmi efektivní!

Nejmenší společný násobek (LCM)

Definice: Nejmenší číslo, které je dělitelné oběma $a$ i $b$.

Vztah s GCD: $\text{lcm}(a, b) = \frac{a \cdot b}{\gcd(a, b)}$

Příklad: $a = 12, b = 18$
$\gcd(12, 18) = 6$
$\text{lcm}(12, 18) = \frac{12 \cdot 18}{6} = \frac{216}{6} = 36$

Ověření: $12 = 2^2 \cdot 3$, $18 = 2 \cdot 3^2$
$\text{lcm} = 2^2 \cdot 3^2 = 36$ ✓

Prvočísla

Definice: Přirozené číslo $p > 1$, které má právě dva dělitele: 1 a sebe sama.

Základní věta aritmetiky: Každé přirozené číslo $n > 1$ lze jedinečně rozepsat jako součin prvočísel (až na pořadí). $$n = p_1^{a_1} \cdot p_2^{a_2} \cdot \ldots \cdot p_k^{a_k}$$

Test primality

Naivní test: Je $n$ prvočíslo? Zkontroluj, zda je dělitelné některým číslem od 2 do $\sqrt{n}$.

def is_prime(n):
    if n < 2:
        return False
    if n == 2:
        return True
    if n % 2 == 0:
        return False
    for i in range(3, int(n**0.5) + 1, 2):
        if n % i == 0:
            return False
    return True

Časová složitost: $O(\sqrt{n})$ — postačující pro středně velká čísla

Poznámka: Pro velmi velká čísla existují pokročilejší testy (Miller-Rabin), které jsou randomizované a polynomu rychlejší.

Faktorizace

Problém: Rozlož číslo $n$ na prvočísla.

Naivní přístup: Postupně dělíme nejmenšími prvočísly.

def factorize(n):
    factors = []
    d = 2
    while d * d <= n:
        while n % d == 0:
            factors.append(d)
            n //= d
        d += 1
    if n > 1:
        factors.append(n)
    return factors

# Příklad: factorize(60)
# → [2, 2, 3, 5]  (protože 60 = 2² × 3 × 5)

Časová složitost: $O(\sqrt{n})$ v nejhorším případě

Důležité: Faktorizace velkých čísel je velmi těžký problém (základ RSA šifrování). Není znám polynomiální algoritmus. Kvantové počítače by ho mohly řešit exponenciálně rychleji (Shorův algoritmus).

Vztah GCD, LCM a prvočísel

Věta: Pokud víme prvočíselný rozklad obou čísel, lze snadno najít GCD a LCM:

  • GCD: Vezmi nejmenší mocniny všech prvočíselů
  • LCM: Vezmi největší mocniny všech prvočíselů
Příklad: $a = 2^3 \cdot 3^2 \cdot 5 = 360$, $b = 2^2 \cdot 3 \cdot 5^2 = 300$

$\gcd(a, b) = 2^2 \cdot 3^1 \cdot 5^1 = 60$
$\text{lcm}(a, b) = 2^3 \cdot 3^2 \cdot 5^2 = 1800$

Ověření: $60 \cdot 1800 = 108000 = 360 \cdot 300$ ✓

Propojení témat v okruhu

Jak se témata navazují:

  1. Rekurence — přesný matematický model pro algoritmy s větvením a opakováním
  2. Speciální funkce — nástroje pro popis a zjednodušení rekurzivních vztahů
  3. Asymptotická notace — jazyk pro popis chování algoritmů (bez konkrétních konstant)

Praktické aplikace: Při návrhu algoritmu vytváříme rekurentní vztahy pro jeho čas běhu, řešíme je (a používáme speciální funkce), a výsledek vyjadřujeme asymptotickou notací, aby byl čitelný a porovnatelný s jinými algoritmy.
