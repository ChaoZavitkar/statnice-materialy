Topologie obvodu

  • Uzel (node): Bod, kde se setkávají tři nebo více větví. V uzlu se proudy dělí nebo slučují.
  • Větev (branch): Část obvodu mezi dvěma uzly — obsahuje jeden nebo více prvků zapojených v sérii.
  • Smyčka (loop): Libovolná uzavřená cesta v obvodu.
  • Síť (mesh): Smyčka, která neobsahuje žádnou jinou smyčku uvnitř (nejjednodušší smyčka).

Sériové a paralelní zapojení rezistorů

Sériové zapojení (stejný proud, napětí se sčítají): $$R_{sér} = R_1 + R_2 + \cdots + R_n$$ Paralelní zapojení (stejné napětí, proudy se sčítají): $$\frac{1}{R_{par}} = \frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n}$$ Pro dva rezistory paralelně: $R_{par} = \frac{R_1 \cdot R_2}{R_1 + R_2}$

Kirchhoffovy zákony

1. Kirchhoffův zákon (KCL — proud)

Znění: Součet všech proudů vstupujících do uzlu se rovná součtu všech proudů vystupujících z uzlu. $$\sum I_{vstup} = \sum I_{výstup} \qquad \text{neboli} \qquad \sum_{k} I_k = 0$$ (proudy vstupující do uzlu jsou kladné, vystupující záporné — nebo naopak)
Příklad: Do uzlu A vstupují proudy $I_1 = 3\,\text{A}$ a $I_2 = 2\,\text{A}$. Kolik je $I_3$ vystupující z uzlu?

$I_1 + I_2 = I_3 \Rightarrow 3 + 2 = 5\,\text{A}$

2. Kirchhoffův zákon (KVL — napětí)

Znění: Součet všech napětí podél libovolné uzavřené smyčky se rovná nule. $$\sum_{k} U_k = 0$$ (napětí zdrojů jsou kladná v jednom smyslu obcházení smyčky, úbytky na prvcích záporná — nebo naopak dle konvence)
Příklad: Jednoduchý obvod: zdroj $U_Z = 12\,\text{V}$, rezistory $R_1 = 4\,\Omega$, $R_2 = 2\,\Omega$ v sérii.
Proud: $I = \frac{U_Z}{R_1 + R_2} = \frac{12}{6} = 2\,\text{A}$
Ověření KVL: $U_Z - U_{R_1} - U_{R_2} = 12 - 8 - 4 = 0\,\text{V}$ ✓

Postup řešení obvodů pomocí KVL a KCL

  1. Označit uzly a větve; zvolit kladný směr proudů v každé větvi
  2. Zapsat rovnice 1. KZ pro každý nezávislý uzel (uzlů − 1 rovnic)
  3. Zvolit smyčky a zapsat rovnice 2. KZ (smyček = větví − uzlů + 1)
  4. Vyřešit soustavu rovnic
  5. Záporný výsledek proudu znamená, že proud teče opačným směrem

Metoda smyčkových proudů

Efektivní metoda pro obvody s více smyčkami. Místo proudů ve větvích zavádíme fiktivní smyčkové proudy $I_A, I_B, \ldots$ procházející každou sítí.

Postup:
  1. Identifikuj sítě (nejjednodušší smyčky) a přiřaď každé smyčkový proud (typicky ve stejném směru — např. po směru hodinových ručiček)
  2. Pro každou síť zapiš KVL rovnici: odporové úbytky = součet napětí zdrojů v síti
  3. Úbytek na rezistoru sdíleném dvěma smyčkami: $R_{12} \cdot (I_A - I_B)$
  4. Vyřeš soustavu rovnic; skutečný proud ve větvi = algebraický součet smyčkových proudů
Příklad — obvod se dvěma sítěmi:
Zdroj $U_1 = 10\,\text{V}$ v síti A, $R_1 = 2\,\Omega$ (jen síť A), $R_{12} = 4\,\Omega$ (sdílený), $R_2 = 6\,\Omega$ (jen síť B), $U_2 = 0$ (žádný zdroj v síti B).

Rovnice pro síť A: $R_1 I_A + R_{12}(I_A - I_B) = U_1$
$\Rightarrow 2I_A + 4(I_A - I_B) = 10 \Rightarrow 6I_A - 4I_B = 10$

Rovnice pro síť B: $R_{12}(I_B - I_A) + R_2 I_B = 0$
$\Rightarrow 4(I_B - I_A) + 6I_B = 0 \Rightarrow -4I_A + 10I_B = 0$

Řešení: Z druhé rovnice $I_A = 2{,}5\,I_B$. Dosadíme: $6(2{,}5I_B) - 4I_B = 10 \Rightarrow 11I_B = 10 \Rightarrow I_B = \frac{10}{11} \approx 0{,}91\,\text{A}$, $I_A \approx 2{,}27\,\text{A}$

Metoda uzlových napětí

Řeší obvod pomocí potenciálů uzlů. Vhodná pro obvody s proudovými zdroji a pro obvody s mnoha uzly.

Postup:
  1. Zvolte referenční uzel (uzemnění, potenciál = 0 V) — typicky uzel s nejvíce připojenými větvemi
  2. Zbylým uzlům přiřaďte neznámé napětí $V_1, V_2, \ldots$ vůči referenci
  3. Pro každý nezávislý uzel zapište rovnici dle 1. KZ: součet odchozích proudů = 0
    Proud ve větvi mezi uzlem $k$ a uzlem $j$ přes odpor $R$: $I_{kj} = \frac{V_k - V_j}{R}$
  4. Vyřešte soustavu rovnic — výsledkem jsou uzlová napětí
Příklad — obvod se dvěma nezávislými uzly (V₁, V₂), reference = 0 V:
$R_1 = 1\,\Omega$ (mezi napájecím napětím $U_S = 12\,\text{V}$ a uzlem $V_1$), $R_2 = 2\,\Omega$ (mezi $V_1$ a $V_2$), $R_3 = 3\,\Omega$ (mezi $V_2$ a referenčním uzlem).

Uzel $V_1$: $\frac{V_1 - 12}{R_1} + \frac{V_1 - V_2}{R_2} = 0 \Rightarrow \frac{V_1 - 12}{1} + \frac{V_1 - V_2}{2} = 0 \Rightarrow 3V_1 - V_2 = 24$
Uzel $V_2$: $\frac{V_2 - V_1}{R_2} + \frac{V_2}{R_3} = 0 \Rightarrow \frac{V_2 - V_1}{2} + \frac{V_2}{3} = 0 \Rightarrow -3V_1 + 5V_2 = 0$

Sečtením: $4V_2 = 24 \Rightarrow V_2 = 6\,\text{V}$, $V_1 = 10\,\text{V}$

Lineární superpozice

Princip superpozice platí pro lineární obvody (obsahující jen rezistory, ideální zdroje, kondenzátory, cívky — bez nelineárních prvků).

Princip: Odezva (proud nebo napětí) lineárního obvodu na více zdrojů současně = algebraický součet odezev na každý zdroj samostatně, přičemž ostatní zdroje jsou nahrazeny jejich vnitřním odporem:
  • Napěťový zdroj → nahradit zkratem (vodičem, $R_{vnitřní} = 0$)
  • Proudový zdroj → nahradit přerušením (otevřeným obvodem, $R_{vnitřní} = \infty$)
Příklad: Obvod se dvěma napěťovými zdroji $U_1 = 6\,\text{V}$ a $U_2 = 4\,\text{V}$, odpory $R_1 = 2\,\Omega$, $R_2 = 3\,\Omega$.

Krok 1 — pouze $U_1$ aktivní ($U_2$ nahrazen zkratem):
$I_1' = \frac{U_1}{R_1 + R_2} = \frac{6}{5} = 1{,}2\,\text{A}$

Krok 2 — pouze $U_2$ aktivní ($U_1$ nahrazen zkratem):
$I_1'' = -\frac{U_2}{R_1 + R_2} = -\frac{4}{5} = -0{,}8\,\text{A}$ (záporné = opačný směr)

Výsledek: $I_1 = I_1' + I_1'' = 1{,}2 - 0{,}8 = 0{,}4\,\text{A}$

Théveninova poučka

Libovolný lineární obvod (z pohledu dvou svorek) lze nahradit jediným napěťovým zdrojem $U_{Th}$ v sérii s odporem $R_{Th}$.

Postup výpočtu $U_{Th}$ a $R_{Th}$:
  1. $U_{Th}$ (napětí naprázdno): Odpoj zátěž. Vypočítej napětí na svorkách bez zátěže.
  2. $R_{Th}$ (Théveninův odpor): Nahraď všechny nezávislé zdroje jejich vnitřním odporem (napěťové zdroje → zkrat, proudové → přerušení). Vypočítej odpor měřený ze svorek.
  3. Náhradní obvod: $U_{Th}$ v sérii s $R_{Th}$. Proudový zdroj zátěží: $I_{zátěž} = \frac{U_{Th}}{R_{Th} + R_{zátěž}}$
Příklad: Obvod: $U_Z = 12\,\text{V}$, $R_1 = 3\,\Omega$, $R_2 = 6\,\Omega$ (dělič napětí). Svorky A-B jsou na $R_2$.

$U_{Th}$: napětí na $R_2$ naprázdno = $U_Z \cdot \frac{R_2}{R_1 + R_2} = 12 \cdot \frac{6}{9} = 8\,\text{V}$

$R_{Th}$: zdroj zkratujeme → $R_1 \parallel R_2 = \frac{3 \cdot 6}{3 + 6} = 2\,\Omega$

S zátěží $R_L = 4\,\Omega$: $I_L = \frac{U_{Th}}{R_{Th} + R_L} = \frac{8}{2 + 4} = \frac{4}{3} \approx 1{,}33\,\text{A}$

Nortonova poučka

Duální k Théveninově poučce — libovolný lineární obvod lze nahradit proudovým zdrojem $I_N$ paralelně s odporem $R_N$.

Postup výpočtu $I_N$ a $R_N$:
  1. $I_N$ (proud nakrátko): Zkratuj svorky. Vypočítej proud tekoucí přes zkrat.
  2. $R_N$: Stejný postup jako $R_{Th}$ — $R_N = R_{Th}$
Vztah k Théveninovi: $$I_N = \frac{U_{Th}}{R_{Th}} \qquad U_{Th} = I_N \cdot R_N \qquad R_N = R_{Th}$$
Příklad (stejný obvod jako výše: $U_{Th} = 8\,\text{V}$, $R_{Th} = 2\,\Omega$):

$I_N = \frac{U_{Th}}{R_{Th}} = \frac{8}{2} = 4\,\text{A}$, $R_N = 2\,\Omega$

S zátěží $R_L = 4\,\Omega$ (paralelně s $R_N$):
$I_L = I_N \cdot \frac{R_N}{R_N + R_L} = 4 \cdot \frac{2}{6} = \frac{4}{3}\,\text{A}$ ✓ (shodný výsledek jako Thévenin)
