KI/SZZPP – Architektura počítačů

Základní principy fungování počítače

Von Neumannova architektura — základ všech moderních počítačů:
  • CPU — provádí instrukce (fetch → decode → execute)
  • Paměť (RAM) — ukládá data i program ve stejném adresovém prostoru
  • Vstup/Výstup — komunikace s periferními zařízeními
  • Sběrnice — propojuje komponenty (adresová, datová, řídicí)

Základní deska (MB)

  • Socket — musí odpovídat CPU (AM5 pro AMD Ryzen 7000+, LGA1700 pro Intel 12.–14. gen)
  • Chipset — určuje podporované funkce (přetaktování, počet PCIe linek, USB portů); např. B650 (AMD střední třída), Z790 (Intel high-end)
  • Formát:
    • ATX (305×244 mm) — plná velikost, nejvíce slotů
    • mATX / Micro-ATX (244×244 mm) — kompaktnější, méně slotů
    • ITX (170×170 mm) — mini PC, jeden slot PCIe, omezené chlazení
  • Sloty a konektory: PCIe ×16 (GPU), M.2 (NVMe SSD), DIMM (RAM), SATA, USB hlavičky, audio
  • VRM (Voltage Regulator Module) — napájení CPU; kvalitní VRM nutné pro přetaktování nebo high-end CPU

Napájecí zdroj (PSU)

Výpočet potřebného výkonu PSU: $$P_{PSU} \geq (P_{CPU} + P_{GPU} + P_{ostatní}) \times 1{,}2$$ Přidejte 20% rezervu pro účinnost a budoucí upgrade.

Příklad: CPU 125 W + GPU 200 W + zbytek 75 W = 400 W → PSU ≥ 480 W → volíme 550 W.

Instalace operačního systému a ovladačů

  1. Vytvoření bootovatelného USB — nástroj Rufus nebo Media Creation Tool (Windows); ISO soubor OS → USB flash disk (min. 8 GB)
  2. Boot z USB — v BIOSu nastavit USB jako první boot zařízení; spustit instalátor
  3. Výběr disku a oddílů — formátovat disk (GPT pro UEFI), vytvořit systémový oddíl
  4. Instalace Windows — průvodce instalací, vytvoření účtu, aktivace licencí
  5. Windows Update — ihned po instalaci spustit aktualizace
  6. Ovladače — chipset (ze stránek výrobce MB), GPU (NVIDIA GeForce Experience / AMD Adrenalin), audio, síťová karta
  7. Ověření — Device Manager (Správce zařízení) — žádná zařízení bez ovladačů (žluté vykřičníky)
Pořadí instalace ovladačů: 1. Chipset → 2. GPU → 3. Zvuk → 4. Síť → 5. Ostatní.
Chipset ovladač musí být první — inicializuje komunikaci CPU ↔ MB a ostatní ovladače na něm závisejí.

  • Tepelná pasta — nanést při montáži CPU chladiče; vyměnit po 3–5 letech (vyschne, zhorší přenos tepla)
  • Airflow ve skříni — přetlak (více přívodních ventilátorů) snižuje prach; podtlak (více výfukových) lépe odvádí teplo
  • Čištění — stlačený vzduch každých 6–12 měsíců; zejména filtry, chladič CPU, GPU radiátor
  • Přetaktování (OC) — zvýšení frekvence CPU/GPU/RAM za výchozí specifikaci; nutné stabilní napájení a lepší chlazení; proveditelné jen s K/X/XT procesorovými verzemi a odpovídajícím chipsetem (Z-series Intel, X-series AMD)
