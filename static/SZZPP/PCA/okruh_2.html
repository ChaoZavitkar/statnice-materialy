KI/SZZPP – Architektura počítačů

Systematický přístup k diagnostice

Zlaté pravidlo diagnostiky: izolace a eliminace.
  1. Reprodukovat problém — ověřit, že problém nastává konzistentně
  2. Shromáždit informace — kdy nastalo, po jaké změně, chybové hlášky
  3. Zúžit příčinu — vyloučit komponenty jednu po druhé (swap test)
  4. Ověřit hypotézu — změnit jednu věc najednou, ne více
  5. Řešit a dokumentovat — zaznamenat závadu a řešení
Checklist před zahájením diagnostiky:
  • Je počítač správně zapojen do sítě? Svítí kontrolky na PSU?
  • Není HW přehřátý? (hmatáním ventilátoru nebo teplotními senzory)
  • Nenastala fyzická změna (nová komponenta, přesun PC, pád)?
  • Byl nedávno nainstalován nový SW nebo ovladač?
  • Jsou v Event Viewer (Prohlížeč událostí) chybové záznamy?

POST a chybové signály

POST (Power-On Self Test) — při každém spuštění MB otestuje základní HW (CPU, RAM, GPU, klávesnici). Pokud test selže, PC se nespustí a signalizuje chybu.

Způsoby signalizace POST chyb:
MetodaPopis
Beep kódyZvukové signály z reproduktoru na MB; vzor závisí na výrobci BIOS (AMI, Award, Phoenix)
POST debug kartaKarta do PCIe/PCI slotu zobrazující hexadecimální kód chyby
Q-LED / POST LEDBarevné LED na moderních MB (červená = CPU, žlutá = DRAM, bílá = GPU, zelená = Boot)
Chybová obrazovkaPokud POST projde, BIOS zobrazí chybu na monitoru
Nejčastější beep kódy (AMI BIOS):
  • 1 krátký pípnutí — POST OK, spouštění OS
  • 3 krátké — RAM chyba (špatně osazená nebo vadná)
  • 1 dlouhý + 2 krátké — GPU chyba (špatně osazená nebo vadná)
  • Nepřetržité pípání — CPU / PSU problém
  • Žádný zvuk + žádný obraz — PSU nebo MB problém

PC se nespustí / černá obrazovka

Vzorová úloha z PDF: „Uživatel si stěžuje, že se počítač nespustí — po zapnutí napájení se zobrazí pouze černá obrazovka."

Systematický checklist — od nejjednodušší příčiny:
  1. Napájení
    • Je PSU zapnutý (přepínač na zadní straně)?
    • Svítí kontrolka na MB (standby LED)?
    • Funguje zásuvka / prodlužovák?
    • Jsou všechny napájecí konektory zapojeny? (24pin MB, 8pin CPU, 6+2pin GPU)
  2. Zobrazení
    • Je monitor napájen a zapnut?
    • Správný vstup na monitoru (HDMI/DP)?
    • Kabel není poškozen?
    • Je GPU správně osazena v PCIe slotu?
  3. RAM
    • Vyjmout a znovu osadit RAM moduly (vyčistit kontakty pryžovou gumou)
    • Zkusit jeden modul v slotu A2 (dle manuálu desky)
    • Q-LED na MB svítí žlutě → RAM problém
  4. GPU
    • Vyjmout a znovu osadit GPU
    • Zkusit monitor přes iGPU (HDMI/DP na základní desce) — pokud funguje, závada v dGPU
    • Q-LED bílá → GPU problém
  5. CMOS Reset
    • Odpojit PC od sítě, vyjmout CMOS baterii na 30 s (nebo jumper CLR_CMOS)
    • Obnoví BIOS do výchozího stavu — opravuje problémy po neúspěšném přetaktování
  6. CPU a MB
    • Zkontrolovat ohnuté piny v socketu (AM5 má piny na CPU, LGA na MB)
    • Ověřit POST LED / beep kódy

Modré obrazovky (BSOD)

BSOD (Blue Screen of Death) = Windows detekoval fatální chybu kernelu a zastavil systém pro ochranu dat.

Čtení BSOD stop kódu:
Příklad: MEMORY_MANAGEMENT (0x0000001A)
  • Textový kód → indikuje kategori problému
  • Hex kód (0x...) → přesný identifikátor chyby
  • Soubor .dmp v C:\Windows\Minidump\ → analyzovat nástrojem WinDbg nebo WhoCrashed

Postup při podezření na vadný disk:
  1. CrystalDiskInfo — zkontrolovat stav (Zdravý / Varování / Špatný)
  2. Ihned zálohovat data! (před jakoukoliv opravou)
  3. chkdsk C: /f /r — opraví logické chyby a označí vadné sektory
  4. Benchmark (CrystalDiskMark) — pomalé čtení/zápis může indikovat degradaci
  5. Výměna disku — klonování (Macrium Reflect, Clonezilla) nebo čistá instalace OS

Přehřívání

Příznaky přehřívání:
  • PC se automaticky vypne při zátěži (thermal shutdown)
  • Snížení výkonu za provozu — CPU/GPU snižuje frekvenci (thermal throttling)
  • Hlučné ventilátory i při nízké zátěži
  • Vysoké teploty v HWiNFO (CPU >90 °C, GPU >90 °C)
Postup řešení přehřívání CPU:
  1. Ověřit teploty — HWiNFO64, zatížit CPU (Prime95, Cinebench)
  2. Zkontrolovat ventilátory — točí se? Jsou čisté?
  3. Vyčistit chladič CPU — stlačený vzduch, kartáček
  4. Vyměnit tepelnou pastu — odborně setřít starou (izopropylalkohol), nanést novou vrstvou velikosti hrášku
  5. Zkontrolovat airflow skříně — volný průchod vzduchu, žádné kabely blokující ventilátory
  6. Zkontrolovat montáž chladiče — dostatečný přítlak na CPU heatspreader
  7. Pokud stále přehřívání → upgrade chlazení nebo snížení TDP v BIOSu (PL1/PL2 limity)

Upgrade komponent

Klíčové kompatibilitní kontroly před upgradem:
UpgradeCo zkontrolovat
CPUStejný socket jako MB; aktualizovat BIOS před montáží nového CPU (nutné pro nové generace)
RAMStejná generace DDR jako MB (DDR4 vs DDR5); ověřit QVL (Qualified Vendor List) desky; max. kapacita per slot
GPUDostatečný PCIe slot (×16); PSU wattáž; délka GPU vs. skříň; napájecí konektory
SSD (upgrade z HDD)Volný M.2 slot (NVMe PCIe 4.0?); nebo SATA port; kapacita pro migraci dat
PSUFormát (ATX); délka vs. skříň; dostatečné konektory pro GPU (12VHPWR pro RTX 40xx)
Kdy upgradovat vs. koupit nový PC?
PřípadDoporučení
Pomalý jen při hráchUpgrade GPU — největší přínos
Pomalé načítání, freezyHDD → SSD — dramatické zlepšení
Málo paměti (RAM <16 GB)Přidat RAM — levný a efektivní upgrade
Starý socket (AM3, LGA1155)Upgrade CPU nevýhodný → nový systém
MB nepodporuje DDR5 / PCIe 4.0Nový systém (MB + CPU + RAM)
BIOS update před CPU upgrade: Nové CPU generace vyžadují aktualizovaný BIOS s podporou nového mikrokódu. Postup: stáhnout BIOS z webu výrobce MB → uložit na USB → Flash BIOS v BIOS/UEFI menu (nebo EZ Flash nástroj). Nikdy nevypínat PC v průběhu flash!
