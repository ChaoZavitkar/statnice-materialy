KI/SZZPP – Základy počítačových sítí a protokolů

Návrh počítačové sítě

Postup návrhu sítě:
  1. Analýza požadavků — počet zařízení, oddělení (VLAN), bezpečnostní požadavky, redundance
  2. Adresní plán — výběr IP rozsahu, VLSM rozdělení subnetů dle požadavků
  3. Návrh fyzické topologie — rozmístění prvků, kabeláž, typy připojení
  4. Návrh logické topologie — VLAN, směrování, bezpečnostní zóny
  5. Bezpečnostní politiky — ACL, VLAN segmentace, VPN, firewall pravidla
  6. Dokumentace — schéma sítě, tabulka IP rozsahů, seznam aktivních prvků

Vzorová úloha ZPS-A — školní síť ve dvou budovách

Zadání: Školní síť ve dvou budovách (A, B) s různými veřejnými IP. Potřeba 7 VLAN (Management, Učitelé, Device, MDevice, Zaměstnanci, Žáci, Hosté).

Požadované výstupy:
  • Tabulka IP rozsahů (VLSM) pro každou VLAN a budovu
  • Schéma sítě s aktivními prvky a jejich funkcemi
  • Výčet bezpečnostních politik
Klíčová rozhodnutí při návrhu:
  • VPN tunel mezi budovami pro přístup ke sdíleným službám (tiskárny, úložiště)
  • VLAN segmentace — Žáci nesmí mít přístup do VLAN Management
  • RADIUS server pro autentizaci v VLAN Učitelé/Zaměstnanci
  • Firewall na hranici každé budovy + mezi VLAN

Konfigurace v Cisco Packet Tracer (ZPS-B)

Packet Tracer je simulátor sítí od Cisco. Konfigurace síťových prvků probíhá přes CLI (IOS příkazy).

Základní IOS příkazy

! Přepnutí do privilegovaného módu
Router> enable
Router#

! Přepnutí do konfiguračního módu
Router# configure terminal
Router(config)#

! Nastavení hostname
Router(config)# hostname R1

! Uložení konfigurace (nutné před exportem PKT souboru!)
R1# copy running-config startup-config
! nebo zkráceně:
R1# do wr

Konfigurace IP adresy na rozhraní

R1(config)# interface GigabitEthernet0/0
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# no shutdown
R1(config-if)# exit

Konfigurace DHCP serveru

! Vyloučit IP adresy ze DHCP poolu (gateway, servery)
R1(config)# ip dhcp excluded-address 192.168.1.1 192.168.1.10

! Definovat DHCP pool
R1(config)# ip dhcp pool VLAN_ZACI
R1(dhcp-config)# network 192.168.1.0 255.255.255.0
R1(dhcp-config)# default-router 192.168.1.1
R1(dhcp-config)# dns-server 8.8.8.8
R1(dhcp-config)# lease 1          ! platnost přidělení v dnech
R1(dhcp-config)# exit

! Ověření DHCP přidělení
R1# show ip dhcp binding
R1# show ip dhcp pool

Konfigurace VLAN na L2 switchích

! Vytvoření VLAN
SW1(config)# vlan 10
SW1(config-vlan)# name ZACI
SW1(config-vlan)# exit

! Access port (pro endpointy)
SW1(config)# interface FastEthernet0/1
SW1(config-if)# switchport mode access
SW1(config-if)# switchport access vlan 10
SW1(config-if)# exit

! Trunk port (pro propojení switch–switch nebo switch–router)
SW1(config)# interface GigabitEthernet0/1
SW1(config-if)# switchport mode trunk
SW1(config-if)# switchport trunk allowed vlan 10,20,30
SW1(config-if)# exit

! Ověření VLAN
SW1# show vlan brief
SW1# show interfaces trunk

Router-on-a-Stick (Inter-VLAN routing)

! Subinterface pro každou VLAN na routeru
R1(config)# interface GigabitEthernet0/0.10
R1(config-subif)# encapsulation dot1Q 10
R1(config-subif)# ip address 10.10.4.1 255.255.255.0
R1(config-subif)# exit

R1(config)# interface GigabitEthernet0/0.20
R1(config-subif)# encapsulation dot1Q 20
R1(config-subif)# ip address 10.10.5.1 255.255.255.0
R1(config-subif)# exit

! Fyzické rozhraní musí být aktivní (no shutdown)
R1(config)# interface GigabitEthernet0/0
R1(config-if)# no shutdown

Dynamické směrování (OSPF)

! Konfigurace OSPF (dynamické zjišťování sousedů, sdílení sítí)
R1(config)# router ospf 1
R1(config-router)# network 10.10.0.0 0.0.255.255 area 0
R1(config-router)# exit

! Ověření OSPF
R1# show ip ospf neighbor
R1# show ip route ospf

Statické směrování

! Statická trasa: ip route [cílová síť] [maska] [next-hop nebo výstupní rozhraní]
R1(config)# ip route 10.20.0.0 255.255.0.0 192.168.100.2

! Výchozí trasa (default route = 0.0.0.0/0)
R1(config)# ip route 0.0.0.0 0.0.0.0 203.0.113.1   ! gateway do internetu

! Ověření
R1# show ip route

NAT konfigurace

! Označit vnitřní rozhraní (privátní síť)
R1(config)# interface GigabitEthernet0/0
R1(config-if)# ip nat inside
R1(config-if)# exit

! Označit vnější rozhraní (internet)
R1(config)# interface GigabitEthernet0/1
R1(config-if)# ip nat outside
R1(config-if)# exit

! PAT (NAT Overload) — sdílení jedné veřejné IP
R1(config)# access-list 1 permit 10.10.0.0 0.0.255.255
R1(config)# ip nat inside source list 1 interface GigabitEthernet0/1 overload

! Ověření
R1# show ip nat translations

Základní zabezpečení — ACL

! Standardní ACL (jen zdrojová IP) — číslovaná
R1(config)# access-list 10 deny 10.10.4.0 0.0.0.255   ! Blokovat VLAN Žáci
R1(config)# access-list 10 permit any

! Aplikovat na rozhraní
R1(config)# interface GigabitEthernet0/0.100
R1(config-subif)# ip access-group 10 in

! Rozšířená ACL (zdroj, cíl, port) — pojmenovaná
R1(config)# ip access-list extended BLOK_SSH
R1(config-ext-nacl)# deny tcp 10.10.4.0 0.0.0.255 any eq 22
R1(config-ext-nacl)# permit ip any any
R1(config-ext-nacl)# exit

Konektivita do internetu — potřebné funkcionality

Ze ZPS-B vzorové úlohy: „Definujte funkcionality/technologie pro zajištění datové konektivity do sítě Internet."
FunkcePopis
NAT/PATPřeklad privátních IP na veřejnou IP ISP
Default route0.0.0.0/0 → gateway ISP — odesílá veškerý internet provoz
DNS resolverNastavit DNS server v DHCP poolu (8.8.8.8, 1.1.1.1, nebo firemní DNS)
FirewallStavová inspekce — povoluje odchozí provoz, blokuje nevyžádané příchozí
VPN (site-to-site)Šifrovaný tunel mezi budovami přes internet (IPsec)
DHCP relay (ip helper-address)Přeposílá DHCP broadcast z různých VLAN na centrální DHCP server

DHCP Relay (ip helper-address)

! Pokud DHCP server není ve stejné síti jako klient,
! router musí přeposílat DHCP dotazy (unicast) na server

R1(config)# interface GigabitEthernet0/0.10
R1(config-subif)# ip helper-address 10.10.9.1    ! IP adresa DHCP serveru
R1(config-subif)# exit

Ověření funkcionality sítě

! Ping — základní test konektivity
R1# ping 8.8.8.8                    ! test internetu
R1# ping 10.10.4.5 source 10.10.5.1 ! ping z jiné VLAN

! Traceroute — zjištění cesty paketu
R1# traceroute 8.8.8.8

! Zobrazení ARP tabulky
R1# show arp

! Zobrazení MAC tabulky switchě
SW1# show mac address-table

! Zobrazení směrovací tabulky
R1# show ip route

! Zobrazení stavu rozhraní
R1# show interfaces GigabitEthernet0/0
R1# show ip interface brief    ! přehled všech rozhraní

! Ověření OSPF
R1# show ip ospf neighbor
R1# show ip ospf database

Tipy pro Packet Tracer:
  • Kliknutí na zařízení → záložka CLI → přímý přístup k příkazovému řádku
  • Simulation mode (hodiny ikona) — krok za krokem sledovat průchod paketu sítí
  • PDU (Add Simple/Complex PDU) — ruční generování paketů pro testování
