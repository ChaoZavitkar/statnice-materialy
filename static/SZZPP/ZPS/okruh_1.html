Adresování v počítačových sítích

MAC adresa (vrstva 2)

48bitová hardwarová adresa síťové karty.
Formát: AA:BB:CC:DD:EE:FF (hexadecimálně, 6 bajtů)
První 3 bajty = OUI (výrobce), poslední 3 bajty = sériové číslo.
Broadcast: FF:FF:FF:FF:FF:FF

IPv4 adresa (vrstva 3)

32bitová logická adresa. Formát: 4 oktety oddělené tečkou: 192.168.1.100

VLSM a výpočet subnetů

VLSM (Variable Length Subnet Masking) — přidělujeme subnety různých velikostí ze společného bloku. Postup:
  1. Seřadit požadované sítě sestupně dle počtu hostů
  2. Vybrat nejmenší prefix, který pojme požadovaný počet hostů ($2^n - 2 \geq$ hostů)
  3. Přidělit adresový blok, poté pokračovat od další volné adresy

IPv6

128bitová adresa. Formát: 8 skupin po 4 hex číslicích: 2001:0db8:85a3::8a2e:0370:7334
Zkracování: :: = jeden nebo více bloků samých nul (pouze jednou v adrese).
Typy: Unicast (jeden příjemce), Multicast (skupina), Anycast (nejbližší z množiny).
Žádný broadcast v IPv6 — nahrazen multicastem.

Klíčové protokoly a služby

ARP (Address Resolution Protocol): Překlad IP → MAC adresa ve stejné síti. Zařízení broadcastuje „Kdo má IP x.x.x.x?" a vlastník odpoví svou MAC adresou. ARP tabulka se cachuje.
DNS (Domain Name System): Překlad doménových jmen → IP adresy. Hierarchická struktura: root servers → TLD servers (.cz, .com) → autoritativní NS. DNS záznamy: A (IPv4), AAAA (IPv6), MX (mail), CNAME (alias), PTR (reverse).
DHCP (Dynamic Host Configuration Protocol): Automatické přidělování IP konfigurace (IP, maska, gateway, DNS). Postup DORA: Discover (broadcast) → Offer → Request → Ack.
NAT (Network Address Translation): Překlad privátních IP ↔ veřejná IP na routeru. Umožňuje více zařízením sdílet jednu veřejnou IP. PAT (Port Address Translation) = NAT Overload — rozlišuje zařízení dle portů.

Klíčové pojmy Wi-Fi:
  • SSID — název bezdrátové sítě (broadcast nebo skrytý)
  • PSK (Pre-Shared Key) — sdílené heslo pro WPA2/WPA3 Personal
  • RADIUS — server pro WPA2/WPA3 Enterprise — každý uživatel má vlastní přihlašovací údaje (802.1X)
  • Kanály 2,4 GHz: kanály 1, 6, 11 se nepřekrývají — použít pro sousední AP
  • Šifrování: WEP (zastaralé, prolomitelné) → WPA → WPA2 (AES/CCMP) → WPA3 (SAE)

VLAN a bezpečnost sítě

VLAN (Virtual LAN)

VLAN logicky odděluje síťový provoz na úrovni přepínačů bez nutnosti fyzicky oddělené infrastruktury. Každá VLAN = samostatná broadcast doména.

Typy portů na switchích:
  • Access port — přiřazen jedné VLAN; připojují se endpointy
  • Trunk port — přenáší více VLAN; používá IEEE 802.1Q tagging (4bytová VLAN značka)
Inter-VLAN routing — komunikace mezi VLAN vyžaduje router nebo L3 switch (Router-on-a-Stick nebo SVIs).
