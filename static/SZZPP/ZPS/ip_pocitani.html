KI/SZZPP – Základy počítačových sítí a protokolů

Základ: jak vypadá IPv4 adresa v binárce

IPv4 adresa = 32 bitů rozdělených na 4 skupiny po 8 bitech (oktet). Každý oktet se zapisuje jako desítkové číslo 0–255.

Příklad: 192.168.1.100 v binárním zápisu:
OktetDesítkověBinárně
1.1921100 0000
2.1681010 1000
3.10000 0001
4.1000110 0100
Celá adresa binárně: 11000000.10101000.00000001.01100100

Převod oktet: desítkové ↔ binární

Hodnota každého bitu v oktetu (zprava doleva — od nejmenší váhy):
Bit 7Bit 6Bit 5Bit 4Bit 3Bit 2Bit 1Bit 0
1286432168421
Příklad: 192 = 128 + 64 = 1100 0000
Příklad: 168 = 128 + 32 + 8 = 1010 1000
Příklad: 255 = 128+64+32+16+8+4+2+1 = 1111 1111 (všechny bity = 1)

Síťová maska a prefix CIDR

Síťová maska = 32bitové číslo, kde vlevo jsou 1 (část sítě) a vpravo 0 (část hosta).
Nikdy nemůže mít uprostřed nulu a pak jedničku — vždy je to blok jedniček, za ním blok nul.

Prefix /n = počet jedničkových bitů v masce zleva.

Vzorce: $$\text{Počet adres} = 2^{(32 - \text{prefix})}$$ $$\text{Počet hostů} = 2^{(32 - \text{prefix})} - 2$$ (odečítáme adresu sítě a broadcast)

Ze sítě zjistit: adresu sítě, broadcast, rozsah hostů

Postup pro 192.168.10.75/26:

Krok 1 — převést adresu a masku do binárky:
192.168.10.75 → 11000000.10101000.00001010.01001011
Maska /26 = 11111111.11111111.11111111.11000000

Krok 2 — adresa sítě = adresa AND maska (bitový součin):
  01001011  (75)
AND
  11000000  (192)
= 01000000  (64)
Adresa sítě: 192.168.10.64

Krok 3 — broadcast = adresa sítě, ale části hosta (nuly v masce) nastavíme na 1:
Zbývající bity (6 bitů): 0000 00 → 11 1111 = 63
Broadcast: 192.168.10.127  (= 64 + 63)

Krok 4 — rozsah hostů = od (adresa sítě + 1) do (broadcast − 1):
192.168.10.65 – 192.168.10.126

Shrnutí:
Adresa sítě192.168.10.64
Broadcast192.168.10.127
Rozsah hostů192.168.10.65 – .126
Počet hostů62 ($2^6 - 2$)
Maska255.255.255.192

Rychlý trik: bez binárky pro /24, /25, /26, /27…

Velikost bloku = $2^{32-\text{prefix}}$. Pro sítě v posledním oktetu (/24 a menší):

Postup: najdi největší násobek velikosti bloku, který je ≤ poslednímu oktetu adresy → to je začátek sítě.
Broadcast = začátek + velikost bloku − 1.

Příklad: 10.0.0.75/26 → blok = 64, násobky: 0, 64, 128… → 64 ≤ 75 < 128 → síť 10.0.0.64, broadcast 10.0.0.127.

Převod masky ↔ prefix (bez tabulky)

Maska → prefix: sečti jedničkové bity ve všech čtyřech oktetech.
255.255.255.192 → 11111111.11111111.11111111.11000000 → 8+8+8+2 = /26

Prefix → maska (postup pro poslední relevantní oktet):
Prefix /27 → 27 bitů jedniček → poslední oktet má 27−24 = 3 jedničky zleva:
1110 0000 = 128+64+32 = 224 → maska 255.255.255.224

Trik: hodnota „hostitelské části" posledního oktetu = $2^{(32-\text{prefix \bmod 8})}$ − to je zároveň velikost bloku.
Maska posledního oktetu = 256 − velikost bloku.
Př: /26 → blok = $2^6$ = 64 → maska = 256 − 64 = 192 ✓
