Datové struktury

Vektor

Základní datová struktura v R — jednorozměrné pole hodnot stejného typu.

v <- c(10, 20, 30, 40, 50)   # numeric vector
v[2]                          # 20  (indexování od 1, ne od 0!)
v[c(1, 3)]                    # 10 30
v[v > 25]                     # 30 40 50  (logické indexování)
length(v)                     # 5
sum(v); mean(v); max(v)       # 150; 30; 50

# Pojmenované prvky
jmena <- c(a = 1, b = 2, c = 3)
jmena["b"]                    # 2

Matice

m <- matrix(1:12, nrow = 3, ncol = 4)  # matice 3×4
m[2, 3]        # prvek na řádku 2, sloupci 3
m[1, ]         # celý 1. řádek (jako vektor)
m[, 2]         # celý 2. sloupec
dim(m)         # 3 4
nrow(m); ncol(m)  # 3; 4

Data frame (datová tabulka)

Nejdůležitější struktura pro práci s daty — tabulka se sloupci různých typů.

df <- data.frame(
  jmeno = c("Anna", "Bob", "Karel"),
  vek   = c(22, 25, 30),
  aktivni = c(TRUE, FALSE, TRUE)
)

df$jmeno        # přístup ke sloupci
df[2, ]         # 2. řádek
df[df$vek > 23, ]  # filtrace — řádky kde vek > 23

nrow(df); ncol(df)
str(df)         # přehled struktury
summary(df)     # statistický přehled

library(dplyr)
library(tidyr)

# Vzorová úloha: StudentsPerformance.csv
df <- read.csv("StudentsPerformance.csv")

# 1. Nový sloupec avg.score (průměr tří skóre)
df <- df %>%
  mutate(avg.score = (math.score + reading.score + writing.score) / 3)

# 2. Filtrování — záznamy kde parental.level obsahuje "high school"
df_hs <- df %>%
  filter(grepl("high school", parental.level.of.education))

# 3. Průměrné avg.score pro každou kombinaci gender × race.ethnicity
df_grouped <- df_hs %>%
  group_by(gender, race.ethnicity) %>%
  summarise(prumer = mean(avg.score, na.rm = TRUE), .groups = "drop")

# 4. Pivot do širokého formátu — gender jako sloupce
df_wide <- df_grouped %>%
  pivot_wider(names_from = gender, values_from = prumer)

# Výběr sloupců
df %>% select(gender, math.score, avg.score)
df %>% select(-writing.score)       # vynechat sloupec

# Řazení
df %>% arrange(desc(avg.score))     # sestupně
df %>% arrange(gender, avg.score)   # více klíčů

# Přejmenování
df %>% rename(pohLavi = gender, etnikum = race.ethnicity)

Vizualizace dat (ggplot2)

Základní struktura ggplot2: 
ggplot(data, aes(x = ..., y = ..., color = ...)) +
  geom_*(...)  +   # typ grafu
  labs(...)    +   # popisky
  theme_*()
Aesthetic mapping (aes): x, y, color, fill, size, shape, alpha 
library(ggplot2)

# Bodový graf (scatter plot)
ggplot(df, aes(x = math.score, y = reading.score, color = gender)) +

Interpretace boxplotu:
  • Box = mezikvartilové rozpětí (IQR) — střední 50 % dat (Q1 až Q3)
  • Čára uvnitř boxu = medián (Q2)
  • Vousy (whiskers) = Q1 − 1,5×IQR a Q3 + 1,5×IQR
  • Tečky za vousy = odlehlé hodnoty (outliers)

Reprodukovatelné reporty (Rmd / Quarto)

Rmarkdown (.Rmd) / Quarto (.qmd) — kombinuje text (Markdown) + R kód v jednom dokumentu. Renderováním vznikne HTML, PDF nebo prezentace.

Poznámky k ZZD zkoušce:
  • Výstupem je .Rmd nebo .qmd soubor + vyrenderovaný HTML nebo PDF
  • Kód musí být komentovaný (co každý blok dělá)
  • Povinná součást: charakteristika dat (co dataset obsahuje, typy proměnných, chybějící hodnoty) a interpretace výsledků
  • U zkoušky jsou dostupné všechny níže uvedené materiály
