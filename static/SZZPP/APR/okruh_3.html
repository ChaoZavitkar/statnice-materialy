Co je třída a objekt

Objektově orientované programování (OOP) je způsob organizace kódu, kde data a funkce, které s nimi pracují, patří k sobě — tvoří objekt.

Základní pojmy:
  • Třída (class): Šablona/vzor, která popisuje, co objekt bude obsahovat a umět. Analogie: výkres domu.
  • Objekt / instance: Konkrétní výtvor podle třídy. Analogie: postavený dům podle výkresu.
  • Atribut: Proměnná patřící objektu (data, stav).
  • Metoda: Funkce patřící objektu (chování).
Kdy použít třídu místo funkce?
  • Pracuješ s entitou, která má stav i chování (např. bankovní účet: zůstatek + vklad/výběr)
  • Potřebuješ více instancí stejného typu (každý student má jméno, věk, znamky…)
  • Kód by jinak přijímal příliš mnoho parametrů (skupinování do objektu)
# Bez třídy — nevýhodné pro více studentů
jmeno1 = "Anna"

Konstruktor __init__

Speciální metoda __init__ se automaticky zavolá při vytvoření instance. Slouží k inicializaci atributů.

Syntaxe: 
def __init__(self, parametr1, parametr2, ...):
    self.atribut1 = parametr1
    self.atribut2 = parametr2
self.atribut — atribut instance; dostupný ze všech metod třídy přes self 
class Student:
    """Třída reprezentující studenta."""

    def __init__(self, jmeno, vek, studijni_obor="Informatika"):
        self.jmeno = jmeno
        self.vek = vek
        self.studijni_obor = studijni_obor
        self.znamky = []  # prázdný seznam — nový pro každou instanci!

# Vytvoření instancí
anna = Student("Anna", 22)
bob = Student("Bob", 25, "Matematika")

print(anna.jmeno)          # Anna
print(anna.studijni_obor)  # Informatika (výchozí hodnota)
print(bob.studijni_obor)   # Matematika
Pozor na mutable výchozí hodnoty! Nikdy nepiš def __init__(self, znamky=[]) — všechny instance by sdílely stejný seznam. Místo toho inicializuj v těle: self.znamky = [].

Metody

Metoda je funkce definovaná uvnitř třídy. Vždy přijímá self jako první parametr.

class Student:

    def __init__(self, jmeno, vek):
        self.jmeno = jmeno
        self.vek = vek
        self.znamky = []

    def pridat_znamku(self, znamka):
        """Přidá známku do seznamu."""
        if not 1 <= znamka <= 5:
            raise ValueError(f"Neplatná známka: {znamka}. Musí být 1–5.")
        self.znamky.append(znamka)

    def prumerna_znamka(self):
        """Vrátí průměrnou známku, nebo None pokud nejsou žádné."""
        if not self.znamky:
            return None
        return sum(self.znamky) / len(self.znamky)

    def prospiva(self):
        """Vrátí True, pokud je průměr lepší než 3."""
        prumer = self.prumerna_znamka()
        return prumer is not None and prumer <= 3.0

# Použití
anna = Student("Anna", 22)
anna.pridat_znamku(1)
anna.pridat_znamku(2)
anna.pridat_znamku(1)

print(anna.prumerna_znamka())   # 1.3333...
print(anna.prospiva())          # True

try:
    anna.pridat_znamku(6)       # ValueError
except ValueError as e:
    print(f"Chyba: {e}")
Metoda vs. funkce:
  • Metoda má přístup ke stavu objektu přes self
  • Voláme ji přes instanci: anna.pridat_znamku(1)
  • self se předává automaticky — nepíšeme ho při volání

Speciální metody (dunder metody)

Speciální metody (nazývané také dunder — double underscore) umožňují třídám reagovat na vestavěné operace Pythonu (print, in, len, porovnávání, …).

__str__ — pro print()

Vrací čitelný textový popis objektu pro uživatele. Zavolá se při print(objekt) nebo str(objekt).

class Student:
    def __init__(self, jmeno, vek):
        self.jmeno = jmeno
        self.vek = vek

    def __str__(self):
        return f"Student: {self.jmeno} (věk: {self.vek})"

anna = Student("Anna", 22)
print(anna)          # Student: Anna (věk: 22)
print(str(anna))     # Student: Anna (věk: 22)
zprava = f"Ahoj, {anna}!"  # f-string volá __str__
print(zprava)        # Ahoj, Student: Anna (věk: 22)!

__repr__ — pro debug a repr()

Vrací technický popis objektu — ideálně výraz, ze kterého lze objekt znovu vytvořit. Zavolá se v interaktivním shellu nebo při repr(objekt).

class Student:
    def __init__(self, jmeno, vek):
        self.jmeno = jmeno
        self.vek = vek

    def __str__(self):
        return f"Student: {self.jmeno} (věk: {self.vek})"

    def __repr__(self):
        return f"Student(jmeno={self.jmeno!r}, vek={self.vek!r})"

anna = Student("Anna", 22)
print(repr(anna))    # Student(jmeno='Anna', vek=22)

# V seznamu se volá __repr__
studenti = [anna, Student("Bob", 25)]
print(studenti)      # [Student(jmeno='Anna', vek=22), Student(jmeno='Bob', vek=25)]
Pravidlo: Pokud definuješ jen jednu, definuj __repr__. Pokud definuješ obě, __str__ je pro uživatele, __repr__ pro vývojáře. Bez __str__ Python použije __repr__ jako náhradní.

__contains__ — pro operátor in

Umožňuje použít operátor in na objekt. Vrací True nebo False.

class Trida:
    """Třída reprezentující školní třídu (skupinu studentů)."""

    def __init__(self, oznaceni):
        self.oznaceni = oznaceni
        self.studenti = []

    def pridat_studenta(self, student):
        self.studenti.append(student)

    def __contains__(self, jmeno):
        """Umožňuje: 'Anna' in trida"""
        for s in self.studenti:
            if s.jmeno == jmeno:
                return True
        return False

    def __str__(self):
        jmena = [s.jmeno for s in self.studenti]
        return f"Třída {self.oznaceni}: {', '.join(jmena)}"

# Použití
trida = Trida("2A")
trida.pridat_studenta(Student("Anna", 22))
trida.pridat_studenta(Student("Bob", 25))

print("Anna" in trida)   # True
print("Karel" in trida)  # False
print(trida)             # Třída 2A: Anna, Bob

Kompletní příklad: třída Kniha

Komplexní příklad zahrnující všechna témata okruhu — konstruktor, metody, výjimky, speciální metody a použití kolekcí.

class Kniha:
    """Třída reprezentující knihu v knihovně."""

    def __init__(self, nazev, autor, rok, isbn):
        if rok < 0 or rok > 2100:
            raise ValueError(f"Neplatný rok vydání: {rok}")
        if not isbn.isdigit() or len(isbn) not in (10, 13):
            raise ValueError(f"Neplatné ISBN: {isbn}")

        self.nazev = nazev
        self.autor = autor
        self.rok = rok
        self.isbn = isbn
        self.vypujcena = False      # stav: je/není vypůjčena

    def vypujcit(self):
        """Vypůjčí knihu. Vyvolá výjimku pokud je již vypůjčena."""
        if self.vypujcena:
            raise RuntimeError(f"Kniha '{self.nazev}' je již vypůjčena.")
        self.vypujcena = True

    def vratit(self):
        """Vrátí knihu. Vyvolá výjimku pokud nebyla vypůjčena."""
        if not self.vypujcena:
            raise RuntimeError(f"Kniha '{self.nazev}' není vypůjčena.")
        self.vypujcena = False

    def je_dostupna(self):
        """Vrátí True pokud je kniha k dispozici."""
        return not self.vypujcena

    def __str__(self):
        stav = "dostupná" if self.je_dostupna() else "vypůjčena"
        return f'"{self.nazev}" — {self.autor} ({self.rok}) [{stav}]'

    def __repr__(self):
        return (f"Kniha(nazev={self.nazev!r}, autor={self.autor!r}, "
                f"rok={self.rok!r}, isbn={self.isbn!r})")


class Knihovna:
    """Kolekce knih."""

    def __init__(self, nazev):
        self.nazev = nazev
        self.knihy = []           # seznam instancí Kniha

    def pridat_knihu(self, kniha):
        self.knihy.append(kniha)

    def najit_knihy_autora(self, autor):
        """Vrátí seznam knih daného autora."""
        return [k for k in self.knihy if k.autor.lower() == autor.lower()]

    def dostupne_knihy(self):
        """Vrátí seznam dostupných knih."""
        return [k for k in self.knihy if k.je_dostupna()]

    def __contains__(self, isbn):
        """Umožňuje: '978...' in knihovna"""
        return any(k.isbn == isbn for k in self.knihy)

    def __str__(self):
        return (f"Knihovna '{self.nazev}': "
                f"{len(self.dostupne_knihy())}/{len(self.knihy)} dostupných knih")


# --- Použití ---
knihovna = Knihovna("Městská knihovna")

k1 = Kniha("Malý princ", "Antoine de Saint-Exupéry", 1943, "9780156013987")
k2 = Kniha("1984", "George Orwell", 1949, "9780451524935")
k3 = Kniha("Farma zvířat", "George Orwell", 1945, "9780451526342")

knihovna.pridat_knihu(k1)
knihovna.pridat_knihu(k2)
knihovna.pridat_knihu(k3)

print(knihovna)          # Knihovna 'Městská knihovna': 3/3 dostupných knih

# Vypůjčení
k1.vypujcit()
print(k1)                # "Malý princ" — Antoine... [vypůjčena]
print(knihovna)          # Knihovna ...: 2/3 dostupných knih

# Test in
print("9780451524935" in knihovna)   # True
print("0000000000" in knihovna)      # False

# Hledání podle autora
orwell = knihovna.najit_knihy_autora("George Orwell")
for kniha in orwell:
    print(kniha)

# Výjimka při druhém vypůjčení
try:
    k1.vypujcit()
except RuntimeError as e:
    print(f"Chyba: {e}")   # Chyba: Kniha 'Malý princ' je již vypůjčena.

# Vrácení
k1.vratit()
print(k1)                  # "Malý princ" — Antoine... [dostupná]

Výjimky v třídách

Výjimky ve třídách se používají stejně jako v běžných funkcích — ale je dobrý zvyk je vyvolávat v metodách, kde je zachytit na místě volání (ne skrývat uvnitř třídy).

Vzory pro výjimky v třídách:
KdeKdyVýjimka
V __init__Neplatná inicializační dataValueError, TypeError
V metoděNeplatný stav nebo argumentyRuntimeError, ValueError
V metoděPrvek nenalezenKeyError, IndexError, vlastní výjimka
 
class BankovniUcet:

    def __init__(self, majitel, pocatecni_zustatek=0):
        if pocatecni_zustatek < 0:
            raise ValueError("Počáteční zůstatek nemůže být záporný")
        self.majitel = majitel
        self.zustatek = pocatecni_zustatek

    def vlozit(self, castka):
        if castka <= 0:
            raise ValueError(f"Vkladaná částka musí být kladná, dostali jsme: {castka}")
        self.zustatek += castka

    def vybrat(self, castka):
        if castka <= 0:
            raise ValueError("Vybraná částka musí být kladná")
        if castka > self.zustatek:
            raise RuntimeError(
                f"Nedostatek prostředků: máte {self.zustatek} Kč, chcete vybrat {castka} Kč"
            )
        self.zustatek -= castka

    def __str__(self):
        return f"Účet {self.majitel}: {self.zustatek:.2f} Kč"

    def __repr__(self):
        return f"BankovniUcet(majitel={self.majitel!r}, zustatek={self.zustatek!r})"


# Testování
ucet = BankovniUcet("Anna", 1000)
ucet.vlozit(500)
print(ucet)         # Účet Anna: 1500.00 Kč

try:
    ucet.vybrat(2000)
except RuntimeError as e:
    print(f"Chyba: {e}")

try:
    ucet.vlozit(-100)
except ValueError as e:
    print(f"Chyba: {e}")
