Základní datové typy a literály

Python má čtyři základní datové typy, se kterými se setkáváme nejčastěji:

TypPříklady literálůPopis
int0, 42, -7, 1_000_000Celé číslo (libovolná velikost)
float3.14, -0.5, 1e6, 2.0Desetinné číslo (IEEE 754)
boolTrue, FalseLogická hodnota (podtyp int: True=1, False=0)
str"ahoj", 'svět', """víceřádkový"""Řetězec znaků (neměnný)

Operace a metody základních typů

int / float — aritmetické operace: + - * / // % **
/ vždy vrátí float  |  // celočíselné dělení  |  % zbytek  |  ** mocnina 
print(7 / 2)    # 3.5
print(7 // 2)   # 3
print(7 % 2)    # 1
print(2 ** 8)   # 256
print(int(3.9)) # 3  — převod na int (ořízne, nezaokrouhlí)
print(round(3.9)) # 4
str — užitečné metody: .upper() .lower() .strip() .split() .join() .replace() .startswith() .endswith() .find() .count() .isdigit() .isalpha() 
s = "  Ahoj, světe!  "
print(s.strip())           # "Ahoj, světe!"
print(s.strip().upper())   # "AHOJ, SVĚTE!"
print(s.strip().split(",")) # ["Ahoj", " světe!"]

slova = ["jedno", "dva", "tři"]
print(", ".join(slova))    # "jedno, dva, tři"

print("hello".replace("l", "r"))  # "herro"
print("12345".isdigit())           # True
print("abcde".isalpha())           # True
Konverze typů: int("42"), float("3.14"), str(100), bool(0)
Falsy hodnoty: 0, 0.0, "", None, False — vše ostatní je truthy.

Proměnné a přiřazení

Python je dynamicky typovaný — typ proměnné se určuje za běhu, ne při deklaraci.

Pravidla pro názvy proměnných: písmena, číslice, podtržítko; nesmí začínat číslicí; rozlišuje velká/malá písmena; konvence: snake_case 
x = 10              # přiřazení
y = x + 5           # použití proměnné
x = "text"          # přetypování — Python dovolí

# Přiřazení více hodnot najednou
a, b, c = 1, 2, 3
a, b = b, a         # záměna hodnot (swap)

# Augmentované přiřazení
pocet = 0
pocet += 1          # ekvivalent: pocet = pocet + 1
pocet *= 2

# Typová anotace (nepovinná, jen pro přehlednost)
jmeno: str = "Anna"
vek: int = 25

Import balíčků

Python má bohatou standardní knihovnu. Balíčky se importují příkazem import.

Způsoby importu:
import math — importuje celý modul, přistupujeme přes math.sqrt()
from math import sqrt, pi — importuje konkrétní jména přímo
from math import * — importuje vše (nedoporučuje se)
import math as m — alias pro kratší zápis

Modul math

import math

print(math.sqrt(16))      # 4.0
print(math.pi)            # 3.141592653589793
print(math.e)             # 2.718281828459045
print(math.floor(3.7))    # 3
print(math.ceil(3.2))     # 4
print(math.log(100, 10))  # 2.0
print(math.factorial(5))  # 120
print(math.pow(2, 10))    # 1024.0
print(math.gcd(12, 8))    # 4

Modul random

import random

print(random.random())          # náhodné float z [0.0, 1.0)
print(random.randint(1, 6))     # náhodné int včetně obou krajů
print(random.uniform(0, 10))    # náhodné float v rozsahu

seznam = [1, 2, 3, 4, 5]
random.shuffle(seznam)          # zamíchá seznam na místě
print(random.choice(seznam))    # náhodný prvek ze seznamu
print(random.sample(seznam, 3)) # 3 různé náhodné prvky
Reprodukovatelnost: Pro testy nebo ladění lze nastavit seed: random.seed(42) — zaručí vždy stejnou sekvenci náhodných čísel.

Interpolace řetězců (f-strings)

F-strings (od Python 3.6) jsou nejpřehlednější způsob sestavování řetězců s proměnnými.

Syntaxe: f"text {výraz} text" — výraz uvnitř {} se vyhodnotí a vloží do řetězce 
jmeno = "Anna"
vek = 25
vyska = 1.654

print(f"Jmenuji se {jmeno} a je mi {vek} let.")
print(f"Výška: {vyska:.2f} m")      # 2 desetinná místa → 1.65
print(f"Výška: {vyska:.0f} m")      # zaokrouhlení → 2

cislo = 42
print(f"{cislo:>10}")   # zarovnání vpravo, šířka 10 znaků
print(f"{cislo:<10}")   # zarovnání vlevo
print(f"{cislo:0>5}")   # doplnění nulami → 00042
print(f"{cislo:b}")     # binárně → 101010
print(f"{cislo:x}")     # hexadecimálně → 2a

pi = 3.14159265
print(f"π ≈ {pi:.4f}")  # π ≈ 3.1416
print(f"π = {pi!r}")    # !r použije repr() → 3.14159265
Přehled formátovacích specifikátorů:
:.2ffloat na 2 desetinná místa
:dcelé číslo
:evědecký zápis (1.23e+02)
:>10zarovnání vpravo, šířka 10
:<10zarovnání vlevo, šířka 10
:^10zarovnání na střed, šířka 10
:,oddělovač tisíců (1,000,000)

Cykly

Cyklus for

Iteruje přes libovolnou sekvenci (seznam, řetězec, range, …).

# Iterace přes range
for i in range(5):          # 0, 1, 2, 3, 4
    print(i)

for i in range(2, 10, 2):  # 2, 4, 6, 8
    print(i)

# Iterace přes řetězec
for znak in "ahoj":
    print(znak)             # a, h, o, j

# Iterace přes seznam
ovoce = ["jablko", "hruška", "švestka"]
for plod in ovoce:
    print(plod)

# enumerate — index + hodnota
for i, plod in enumerate(ovoce):
    print(f"{i}: {plod}")   # 0: jablko, 1: hruška, ...

# range s krokem dozadu
for i in range(10, 0, -1):
    print(i)                # 10, 9, ..., 1

Cyklus while

Opakuje blok, dokud je podmínka pravdivá.

n = 1
while n <= 5:
    print(n)
    n += 1

# Klasický "nekonečný" cyklus s podmínkou uvnitř
while True:
    vstup = input("Zadej číslo (q = konec): ")
    if vstup == "q":
        break               # ukončí cyklus
    print(f"Zadal jsi: {vstup}")

break, continue, else

# break — okamžitě ukončí cyklus
for i in range(10):
    if i == 5:
        break
    print(i)   # 0, 1, 2, 3, 4

# continue — přeskočí zbytek iterace
for i in range(10):
    if i % 2 == 0:
        continue
    print(i)   # 1, 3, 5, 7, 9

# else na cyklu — spustí se, POKUD cyklus nebyl ukončen break
for i in range(5):
    if i == 10:
        break
else:
    print("Cyklus proběhl bez přerušení")
Kdy použít for vs. while: for — known number of iterations or iterating over collection; while — iteration count not known in advance (user input, convergence, etc.)

Vlastní funkce

Syntaxe: 
def název_funkce(parametr1, parametr2, ...):

Poziční a pojmenované parametry

def pozdrav(jmeno, pozdrav="Ahoj"):
    """Pozdraví osobu. Výchozí pozdrav je 'Ahoj'."""
    return f"{pozdrav}, {jmeno}!"

# Volání poziční
print(pozdrav("Anna"))          # Ahoj, Anna!
print(pozdrav("Bob", "Čau"))    # Čau, Bob!

# Volání pojmenované (keyword argument)
print(pozdrav(pozdrav="Dobrý den", jmeno="Karel"))  # Dobrý den, Karel!
def bmi(hmotnost, vyska):
    """Vypočítá BMI."""
    return hmotnost / vyska ** 2

vysledek = bmi(70, 1.75)
print(f"BMI: {vysledek:.1f}")   # BMI: 22.9

# Více návratových hodnot (vrací tuple)
def min_max(cisla):
    return min(cisla), max(cisla)

minimum, maximum = min_max([3, 1, 4, 1, 5, 9])
print(minimum, maximum)  # 1 9

Parametry *args a **kwargs

def soucet(*args):
    """Sečte libovolný počet čísel."""
    return sum(args)

print(soucet(1, 2, 3))       # 6
print(soucet(1, 2, 3, 4, 5)) # 15

def info(**kwargs):
    """Vypíše klíče a hodnoty."""
    for klic, hodnota in kwargs.items():
        print(f"{klic} = {hodnota}")

info(jmeno="Anna", vek=25, mesto="Praha")
Pravidlo pořadí parametrů:
def f(poziční, *args, s_výchozí=hodnota, **kwargs)
Parametry s výchozí hodnotou musí být za parametry bez výchozí hodnoty.

Výjimky

Výjimky signalizují chybový stav za běhu programu. Python je objektový systém — každá výjimka je instance třídy.

Zachycení výjimky (try/except)

try:
    cislo = int(input("Zadej číslo: "))
    vysledek = 10 / cislo
    print(f"10 / {cislo} = {vysledek}")
except ValueError:
    print("Chyba: to není číslo!")
except ZeroDivisionError:
    print("Chyba: nelze dělit nulou!")
except Exception as e:
    print(f"Neočekávaná chyba: {e}")
else:
    # spustí se pouze pokud NENASTALA žádná výjimka
    print("Výpočet proběhl úspěšně")
finally:
    # spustí se VŽDY (i při výjimce)
    print("Konec výpočtu")

Vyvolání výjimky (raise)

def odmocnina(x):
    if x < 0:
        raise ValueError(f"Odmocnina záporného čísla nedefinována: {x}")
    return x ** 0.5

try:
    print(odmocnina(-4))
except ValueError as e:
    print(f"Chyba: {e}")

while True:
    try:
        vek = int(input("Zadej věk (0-150): "))
